# LEAN — καρνέ προπόνησης

Εφαρμογή καταγραφής προπόνησης για αθλητικό, γραμμωμένο σώμα. Full-body τρεις φορές την εβδομάδα, με αυτόματο έλεγχο διπλής προοδευτικότητας, παρακολούθηση λόγου ώμων προς μέση και υπολογισμό διατροφικών στόχων.

Στατικό site χωρίς build step και χωρίς εξαρτήσεις. Ανεβαίνει ως έχει στο GitHub Pages.

## Τι κάνει

- **Προπόνηση** — τρεις ημέρες (Α/Β/Γ) με προκαθορισμένες ασκήσεις, σετ, εύρη επαναλήψεων και χρόνους ξεκούρασης. Καταγράφεις κιλά και επαναλήψεις ανά σετ με δύο πατήματα.
- **Διπλή προοδευτικότητα** — όταν κλειδώσεις όλα τα σετ στο πάνω όριο του εύρους, η άσκηση σου προτείνει το επόμενο βάρος. Δεν χρειάζεται να το θυμάσαι.
- **Χρονόμετρο ξεκούρασης** — ξεκινά μόνο του μετά από κάθε σετ, με τον σωστό χρόνο για σύνθετη ή μονωτική άσκηση. Δονεί όταν τελειώσει.
- **Πρόοδος** — εκτιμώμενο 1RM ανά άσκηση, σωματικό βάρος με κυλιόμενο μέσο όρο, λόγος ώμων προς μέση, εβδομαδιαίος όγκος ανά μυϊκή ομάδα.
- **Διατροφή** — Mifflin-St Jeor, με στόχους για recomposition, γράμμωση ή lean bulk.
- **Οδηγός** — το σκεπτικό πίσω από κάθε επιλογή του προγράμματος.

Τα δεδομένα μένουν στη συσκευή σου. Το Supabase είναι προαιρετικό.

## Ανέβασμα στο GitHub Pages

```bash
git init
git add .
git commit -m "Πρώτη έκδοση"
git branch -M main
git remote add origin https://github.com/USERNAME/lean-athletic.git
```

Μετά, στο repo: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `root` → Save.**

Σε ένα δύο λεπτά θα είναι ζωντανό στο `https://USERNAME.github.io/lean-athletic/`.

Το αρχείο `.nojekyll` υπάρχει ώστε το GitHub να σερβίρει τους φακέλους ως έχουν.

Χωρίς αυτό όλα δουλεύουν, απλώς τα δεδομένα ζουν σε μία συσκευή. Με αυτό, σε ακολουθούν σε κινητό και υπολογιστή.

Οι πίνακες είναι **ήδη στημένοι** στο project `Barber Booking` (ref `sdddhzrbqkfayodyjnnz`). Έχουν πρόθεμα `lean_` ώστε να μην ακουμπούν τους 12 πίνακες του barber app που ζουν στην ίδια βάση.

Στην εφαρμογή: **Ρυθμίσεις → Συγχρονισμός με Supabase** → επικόλλησε URL και key → Αποθήκευση → Δοκιμή σύνδεσης.

```
URL:  https://sdddhzrbqkfayodyjnnz.supabase.co
Key:  sb_publishable_Pz_tirRe8zJ2JZV6VC4K1g_TNyp_nDe
```

Για καθαρό project από το μηδέν, τρέξε το `supabase/schema.sql` στον SQL Editor.

Από εκεί και πέρα κάθε εγγραφή ανεβαίνει αυτόματα. Το κουμπί «Φέρε από το cloud» κατεβάζει τα πάντα σε μια καινούρια συσκευή.

### Σημείωση ασφάλειας

Οι τρεις πίνακες `lean_*` έχουν RLS ενεργό αλλά με πολιτική που επιτρέπει ανάγνωση και εγγραφή σε οποιονδήποτε έχει το key. Επειδή το key ταξιδεύει μέσα στη σελίδα, **όποιος ανοίξει τα developer tools στο site σου μπορεί να δει το ημερολόγιο προπόνησής σου**.

Για προσωπικό καρνέ είναι αποδεκτό. Αν κάνεις το repo δημόσιο και σε ενοχλεί, ενεργοποίησε το δεύτερο μπλοκ πολιτικών στο `schema.sql` και πρόσθεσε Supabase Auth.

Οι πίνακες του barber app **δεν επηρεάστηκαν** — κρατούν τις δικές τους πολιτικές.

## Προσαρμογή

Το πρόγραμμα ζει ολόκληρο στο `PROGRAM` μέσα στο `data.js`. Για να αλλάξεις άσκηση, σετ ή εύρος επαναλήψεων, πείραξε μόνο εκείνο το αντικείμενο — η υπόλοιπη εφαρμογή προσαρμόζεται.

Το `step` ελέγχει το βήμα αύξησης βάρους: 2.5 kg για σύνθετες, 1 kg για μονωτικές. Αν το γυμναστήριό σου έχει μικρότερα πλακίδια, χαμήλωσέ το.

## Σχεδιαστικές επιλογές

Η παλέτα βγαίνει από τα χρώματα των πιστοποιημένων δίσκων: μπλε των 20 κιλών για τις ενέργειες, κίτρινο των 15 για τη στιγμή που κερδίζεις βάρος, πράσινο για ολοκληρωμένο. Η τυπογραφία είναι Roboto Condensed για τα νούμερα και IBM Plex Sans για τα υπόλοιπα, επειδή η εφαρμογή διαβάζεται όρθιος και με το ένα χέρι. Όλοι οι στόχοι αφής είναι τουλάχιστον 46 pixel.
